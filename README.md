# 📱 Project Hub

> App que conecta investidores a pessoas que possuem ideias e projetos.

## 🎯 Problema que resolve

Muitas pessoas têm boas ideias de negócio, mas não sabem como encontrar quem possa investir nelas. Da mesma forma, investidores têm dificuldade em descobrir projetos promissores de forma direta. O Project Hub aproxima os dois lados em um só lugar.

## 🚀 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/MURILOSOTELE/Project-hub.git

# Instale as dependências
cd Project-hub
npm install

# Inicie o app
npx expo start
```

Abra o app **Expo Go** no celular e escaneie o QR Code gerado.

## 🛠️ Tecnologias

- React Native + Expo Go
- React Navigation
- AsyncStorage
